# BOOTV

동영상을 원하는 구간만 잘라내고, 등장하는 **얼굴을 자동으로 모자이크**하는 도구입니다.

## 설치

Python 3.9 이상이 필요합니다.

```bash
pip install -r requirements.txt
```

- ffmpeg는 `imageio-ffmpeg` 패키지에 들어 있어서 따로 설치하지 않아도 됩니다. 이미 설치된 ffmpeg가 있으면 그것을 먼저 씁니다.
- 얼굴 인식 모델(약 1MB)은 처음 실행할 때 `models/` 폴더에 자동으로 내려받아집니다.

## 사용법

```bash
# 영상 전체 얼굴 모자이크 → input_edited.mp4 로 저장
python blur.py input.mp4

# 1분 10초 ~ 1분 40초만 잘라서 모자이크
python blur.py input.mp4 --start 1:10 --end 1:40

# 저장 파일 이름 지정, 모자이크 대신 흐림 효과
python blur.py input.mp4 -o result.mp4 --mode blur

# 모자이크 없이 자르기만
python blur.py input.mp4 --no-blur --start 0:05 --end 0:20

# 가리기 전에 얼굴이 제대로 잡히는지 빨간 상자로 확인
python blur.py input.mp4 --preview --end 0:10
```

시간은 `90`(초), `1:30`, `0:01:30.5` 형식 모두 됩니다. 소리는 그대로 유지되고, 휴대폰으로 세로 촬영한 영상의 방향도 그대로 반영됩니다.

## 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--start`, `--end` | 처음/끝 | 잘라낼 구간 |
| `--mode` | `mosaic` | `mosaic`(모자이크), `blur`(흐림), `black`(검은 상자) |
| `--strength` | 15 | 클수록 모자이크 블록이 굵어지고 흐림이 강해짐 |
| `--padding` | 0.25 | 얼굴 상자를 넓히는 비율 (머리카락·턱까지 가리려면 키우기) |
| `--confidence` | 0.5 | 낮추면 얼굴을 더 많이 잡지만 엉뚱한 곳도 가려짐 |
| `--tiles` | 4 | 화면을 나눠서 작은 얼굴까지 찾음. 줄이면 빨라지고 늘리면 먼 얼굴도 잡음 |
| `--hold` | 15 | 얼굴을 잠깐 놓쳐도 이 프레임 수만큼 계속 가림 (깜빡임 방지) |
| `--crf` | 20 | 화질 (낮을수록 고화질·큰 파일, 18~28 권장) |
| `--no-blur` | | 자르기만 하기 |
| `--preview` | | 가리지 않고 인식 위치만 빨간 상자로 표시 |

## 잘 안 될 때

- **멀리 있는 작은 얼굴이 빠짐** → `--tiles 5 --confidence 0.4`
- **얼굴이 잠깐씩 드러남** → `--hold 30`
- **처리가 너무 느림** (얼굴이 화면에 크게 나올 때) → `--tiles 2`
- **얼굴이 아닌 곳이 가려짐** → `--confidence 0.6`

> ⚠️ 자동 인식은 옆얼굴, 뒤돌아선 얼굴, 가려진 얼굴, 아주 작은 얼굴을 놓칠 수 있습니다. 공개하기 전에 결과 영상을 반드시 직접 확인하세요.
